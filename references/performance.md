# 速度、成本与不减项原则

1. 固定本地代码，不让模型每次重新写软件或逐页阅读原文。程序不请求外部 LLM，不为文档正文消耗云端分析 token；与 Agent 对话的普通说明仍会产生对话开销。
2. spaCy 模型进程内复用，去重文本用 nlp.pipe 批量语义识别；确定性规则仍检查所有提取区域。
3. OCR 仅在进程内有限 LRU 缓存（8 幅输入图像），缓存结果深拷贝，防止复核修改污染下一任务；会话关闭清空。没有明文磁盘 OCR 缓存。
4. 加密任务仅保存有内容的正文/OCR/公式及有命中的结构属性，不保存海量无命中的结构值；扫描范围不缩减。图文复核采用键与快照内容匹配，不再依赖数组序号碰巧对应。
5. 复用解析后的脱敏输出做检查与占位符计数，避免同一导出件重复解析；工作台预览最多保留2份解析文档。
6. Office 额外 PDF 为可选，避免每个普通任务都启动 LibreOffice。原有 PDF 必须渲染重建，不为了速度跳过像素层检查。
7. 单批100份 / 250 MB，单文件100 MB，PDF60页，Office展开300 MB，图片3500万像素；极端文件阻断，不静默丢页。
8. 加密任务含完整原件，批处理仍需要内存。多页扫描或大课件会慢，不承诺所有案件秒级处理。异常时不会改用云端 OCR。

实测方法与数字见发行验收报告；性能值不包含人工复核时间，不作为任意真实文件的耗时保证。
