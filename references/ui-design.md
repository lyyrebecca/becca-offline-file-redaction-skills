# 桌面 UI 与品牌规范

用户提供原样素材：`assets/ui-reference.png`、`assets/brand-icon.jpg`。不替换为新生成的标志。

- 深墨紫 #150A35：固定侧栏、主要文字、主要按钮。
- 薰衣草 #A577FF：步骤高亮、选择、进度、框选。
- 浅底 #F5F7FC：工作台背景；白色卡片、细分隔线。
- 正文对比度优先，紫色不是正文大面积底色；次要文字与控件需可读。
- 桌面四步：场景与目的 / 导入与整理 / 本机复核 / 交付与恢复。
- 本地文件选择、多文件拖放、可选文件夹路径导入；不能把材料悄悄上传网站。
- 导入队列为每个临时副本提供移除按钮，不影响原文件；一个批次默认同属 CASE001，不要求逐文件确认案件/材料类别。复核使用材料导航、格式预览、命中项、原图与像素遮挡预览；手工矩形可删除，改动后必须重新确认文件。
- 文本区域允许鼠标拖选漏检内容并显式选择类别；提交前提示“本批所有相同字面量均会处理”。连续数字和字母数字编码仅在可见文本/OCR 中独立列出并默认不打码；内部来源锚点及结构字段不作为该类候选。用户可勾选后保存。可选将精确词条加密持久保存，明确告知未来复用需要同一保险库口令。右键单条命中须二次确认并记录本机人工保留理由。
- 所有批次级修改后清除受影响文件的“已复核”状态；显示影响范围并要求最终完整人工复核，禁止把一次选择表述为自动学习语义。连续数字/编码候选单列并默认不打码。图片自动黑块标注位置编号并可跳转到候选；手工遮挡编号可移除后重画。
- 真实进度按已完成文件计数；不虚构整体耗时或百分比。OCR 首次加载及大文件可较慢。
- 状态不能只靠颜色区分；必须显示“检查通过 / 待复核 / 失败”的文字。
- 所有脚本、样式、字体回退及图标本地化，无 CDN、统计像素、远程字体。
- 窄屏可堆叠；Windows 与 macOS 桌面均为主验收平台。支持系统减少动画设置和键盘焦点。
- 原文页面禁止云端视觉验收；仅合成样本可截图测试。

平台启动器（Windows 快捷方式 / `信息隐身衣.cmd`、macOS `.app`、Linux 应用菜单项）都是轻量入口：打开固定本地引擎与默认浏览器工作台，不是网站托管，也不是携带所有依赖的独立原生应用。程序退出按钮停止本地服务并清理会话缓存；仅关闭浏览器标签页不会停止后台会话。

交付页必须提供醒目的“一键打开交付文件夹”链接（本机服务调用系统文件管理器：Windows 资源管理器 / macOS Finder / Linux xdg-open）与“复制文件夹路径”按钮；不得只在日志或报告里藏路径。路径须完整显示，不要求用户自行推算。普通网页不能保证直接打开任意本机路径，不能将 file:// 当作唯一方案。

启动器采用单次启动后退出＋本地引擎会话复用；重新打开用独立本机激活令牌生成新的一次性浏览器引导链接，不重复启动模型。控制令牌保存在用户本地权限600的会话文件，不含口令或案件原文，退出会清理。
