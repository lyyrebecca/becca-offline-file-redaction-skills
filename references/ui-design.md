# 桌面 UI 与品牌规范

用户提供原样素材：`assets/ui-reference.png`、`assets/brand-icon.jpg`。不替换为新生成的标志。

- 深墨紫 #150A35：固定侧栏、主要文字、主要按钮。
- 薰衣草 #A577FF：步骤高亮、选择、进度、框选。
- 浅底 #F5F7FC：工作台背景；白色卡片、细分隔线。
- 正文对比度优先，紫色不是正文大面积底色；次要文字与控件需可读。
- 桌面四步：场景与目的 / 导入与整理 / 本机复核 / 交付与恢复。
- 本地文件选择、多文件拖放、可选文件夹路径导入；不能把材料悄悄上传网站。
- 复核使用材料导航、命中项、原图与像素遮挡预览；手工矩形可删除，改动后必须重新确认文件。
- 真实进度按已完成文件计数；不虚构整体耗时或百分比。OCR 首次加载及大文件可较慢。
- 状态不能只靠颜色区分；必须显示“检查通过 / 待复核 / 失败”的文字。
- 所有脚本、样式、字体回退及图标本地化，无 CDN、统计像素、远程字体。
- 窄屏可堆叠；桌面适配 Windows / macOS，分别记录真实验收范围。支持系统减少动画设置和键盘焦点。
- 原文页面禁止云端视觉验收；仅合成样本可截图测试。

显示在欢迎侧栏、关于窗口、说明及 Skill 引导中；不默认向案件文件、Markdown 法律材料或原件加入广告、联系方式与水印。不虚构作者学历、职业资质或经历。关于页的外链只有用户主动点击才会打开，核心处理不访问它们。

macOS 应用是轻量启动器：打开固定本地引擎与默认浏览器工作台，不是网站托管，也不是携带所有依赖的独立原生应用。程序退出按钮停止本地服务并清理会话缓存；仅关闭浏览器标签页不会停止后台会话。

交付页必须提供醒目的“一键打开交付文件夹”链接（本机服务调用 Windows 资源管理器 / macOS Finder）与“复制文件夹路径”按钮；不得只在日志或报告里藏路径。路径须完整显示，不要求用户自行推算。普通网页不能保证直接打开任意本机路径，不能将 file:// 当作唯一方案。

启动器采用单次启动后退出＋本地引擎会话复用；重新打开用独立本机激活令牌生成新的一次性浏览器引导链接，不重复启动模型。控制令牌保存在用户本地权限600的会话文件，不含口令或案件原文，退出会清理。

Windows 使用原生开始菜单快捷方式和用户指定图标、独立cmd启动入口；不可复用macOS的.app/.command。系统差异仅影响外壳，身份/用途/归类/复核/交付与恢复共用同一逻辑。
