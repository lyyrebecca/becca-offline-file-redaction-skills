# 文件覆盖与停止条件

## DOCX

直接编辑 OOXML，不用重建整份 Word 文档的方法替换正文。跨 run 的命中只改必要文本，保留段落、run 和样式结构。识别范围包括正文、表格、页眉页脚、脚注尾注、文本框、批注、修订删除文字与隐藏文字；检查属性值中的作者、替代文本等。

元数据清空，缩略图替换为空白图，超链接目标改成 `about:blank`，避免隐藏目标泄露。格式变化后必须本地渲染检查。目录及交叉引用可能含动态域；非受支持域会阻断，允许的域仅 PAGE/NUMPAGES/SECTIONPAGES/TOC/REF/PAGEREF。包含敏感引用名时阻断，不擅自更改引用关系。

原件不接受修订、不删除批注；脱敏工作副本保留可处理的审阅结构，但作者等个人信息去标识化。

## XLSX

覆盖共享字符串、内联字符串、隐藏工作表、单元格、批注、批注作者、超链接和XML属性。改动单元格自动换行，并按原列宽增大行高，避免长占位符被截断；不更改公式或全表列宽。数字、公式及缓存也检查；公式或工作表/命名范围等结构引用含敏感内容时阻断，不能把身份证直接换成文本后仍声称公式正确。无敏感内容的算术公式保留。纯数字身份标识转换为文本占位符；若工作簿同时存在公式，则保守阻断该转换，避免改变依赖计算。编辑后恢复不强行推断这类标识的原数字类型；需要精确原类型可取回原件。普通批注的 VML 为 XML，纳入扫描。

外部数据链接、数据连接、查询、透视缓存、图表缓存均阻断。不自动重算公式；用户在本机 Office/LibreOffice 打开后验算。

## PPTX

覆盖幻灯片、隐藏页、母版、备注、形状文本、替代文本及相关属性。备注与隐藏页不因不可见而跳过。

## 图片与扫描件

PNG/JPEG 重新编码，去除 EXIF；Office 内嵌 PNG/JPEG 同样经过本地 Tesseract。OCR 命中对应像素矩形实心黑块，垂直边界外扩4像素，水平按字符宽度额外外扩以覆盖OCR边缘误差；在本地页面显示原图、脱敏预览，并允许手动补充矩形。OCR 不识别人脸、手写签名、二维码语义；用户必须视觉检查并手动遮挡。没有 OCR 文本也不能省略图片确认。

GIF/TIFF/WebP/SVG/EMF/WMF、多帧图片不是本版原生支持对象；Office 遇到这些不支持媒体会阻断，不当作无隐私。

## PDF

逐页以180 DPI渲染，OCR定位后遮盖，重建只有图像的 PDF；不复制原始 PDF 的文字、附件、批注、元数据或历史对象。可见批注在渲染后属于页面像素，仍需检查。输出不再可搜索、不可原位编辑；最多60页，保留页面比例但不承诺原物理尺寸完全一致。恢复时仅按字节取回加密原件。

## 明确阻断与确定性清理

- 阻断：宏/旧式Office、损坏/加密未解锁文件、包类型不符、重复/路径穿越ZIP成员、DTD实体、未知二进制、OLE、ActiveX、altChunk、图表、动态数据源、数字签名包、复杂人员部件、非空自定义XML，以及敏感公式或结构引用。
- 可安全清理：空的标准书目 Sources 自定义XML及其属性部件；打印机设置二进制及引用（保留XML页面尺寸与页边距）；预览缩略图；XML注释与处理指令；Office属性值。
- 不删除非空书目库以冒充完成；这类输入需用户先制作静态工作副本。
- 单文件上限100 MiB，ZIP解压总量300 MiB，最多10,000成员，图片最多35,000,000像素；超限明确失败。

## 编辑后恢复

精确替换当前任务的完整占位符，并核对每个文件的占位符数量。缺失、复制、未知任务token、损坏前缀均进入冲突清单，不写恢复稿。占位符数量不变但被人为交换位置，程序无法判断法律语义是否正确，仍需本地复核。

批注与修订中完整token可恢复；外部增加的新文字保留，不自动认定为安全。Office内嵌图片只有其脱敏字节未改动时才取回原图片，否则阻断合并。整个图片被外部删除时不会重新强行插入；原图仍可通过取回原件获得。原文档属性不恢复到编辑后稿，以免把已清理元数据重新扩散。
