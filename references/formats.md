# 文件覆盖与停止条件

当前引擎支持 DOCX、XLSX、PPTX、PDF、PNG/JPEG、UTF-8 TXT/Markdown、CSV/TSV、JSON、XML、LOG，以及**受限的单段 text/plain EML**。对受支持格式以完整源文本或结构化单元定位；复杂邮件、未知二进制、旧 Office、含附件/多部件/HTML 的邮件不视作“无敏感信息”，而是阻断。不要承诺“所有文件类型均支持”：导入时必须按白名单解析，其他类型先在可信本机转换为静态副本或停止。

## CSV / TSV、JSON、XML、LOG

- CSV/TSV 使用 UTF-8 文本扫描并先验证可解析；除通用识别外，可依据明确列标题提示姓名、电话、邮箱、社交账号、证件、账户、信用代码、执业证、车辆、产权、案号、地址、日期和金额字段。表头只提供有限字段上下文，候选仍须逐项复核；脱敏只替换原文命中，不重排行列、分隔符、引号或换行。不得将导入的 CSV 当作安全电子表格：不执行公式；对可疑公式注入及业务结构另行本机检查。
- JSON 先解析验证，输出再次解析验证；XML 使用禁网、禁实体解析器，拒绝 DTD，并在输出后再次验证。命中跨越结构边界、导致格式无效时失败，不写出交付副本。
- LOG 按 UTF-8 原文扫描；日志中的令牌、路径、设备标识和用户 ID 可能属于凭证/间接身份线索，仍须人工复核。
- 这些格式保留原始文本布局并以占位符替换，但不保证编码声明、注释语义、业务 schema 或下游软件逻辑。仅支持 UTF-8 输入。

## EML 邮件

接受单段 `text/plain` 邮件，可解码声明字符集下的 Base64/quoted-printable 正文，并复核 From/To/Cc/Bcc/Reply-To/Sender、Subject/Date/Message-ID 等选定头字段和解码正文。HTML、multipart、附件、不支持字符集和解析缺陷一律失败关闭。脱敏输出重建为规范化纯文本 MIME 复核副本，标准头字段映射为 `X-LPC-*` 不透明头，仅保留已呈现复核的字段与正文；其他自定义/技术邮件头被移除并产生明确复核提示。不得把输出当作可直接发送的原始邮件；原件仅由加密保险库恢复。

选中新增的字面内容时，可把该精确字面量映射到本批全部文件的文本/OCR 命中；必要时可选择将规则写入本机 AES-GCM 加密学习库。学习库使用任务口令加密，未来任务只有复用同一口令才能自动载入；口令不匹配时跳过载入，不覆盖旧库。已识别且足够特异的精确字面量会额外在同一文件内产生复核候选，不跨文件自动关联；学习仅是用户确认的**精确字面匹配**，不推断同义词、变体、同名主体或新类别。共享范围扩大前必须核实所有同字面命中；跨案件同名/常见词应先拆任务或用更具体的选区。

## 复核候选与可视预览

- 连续长数字或同时包含字母与数字的编码仅在用户可见文本、表格单元格文本和 OCR 文本中作为 `REVIEW_CODE` 低置信度候选单独列出，默认不打码；日期样式不纳入该规则。XML/Office 结构字段、公式引用及系统生成的内部来源锚点不作为此类用户编码候选，也不会仅因含数字/编码而触发结构阻断。最终仍由用户结合语境决定是否打码。
- 图片/PDF 页面预览会给自动遮挡矩形编号并关联到对应文字命中；人工拖框的矩形编号可移除，删除后可重新框选。标签和实际遮挡共用同一位置数据，操作后必须重新确认文件。

## DOCX

直接编辑 OOXML，不用重建整份 Word 文档的方法替换正文。跨 run 的命中只改必要文本，保留段落、run 和样式结构。对外可见的命中统一写成 `***`，原文与位置映射只保存在加密保险库中。识别范围包括正文、表格、页眉页脚、脚注尾注、文本框、批注、修订删除文字与隐藏文字；检查属性值中的作者、替代文本等。

元数据清空，缩略图替换为空白图，超链接目标改成 `about:blank`，避免隐藏目标泄露。格式变化后必须本地渲染检查。目录及交叉引用可能含动态域；非受支持域会阻断，允许的域仅 PAGE/NUMPAGES/SECTIONPAGES/TOC/REF/PAGEREF。包含敏感引用名时阻断，不擅自更改引用关系。

原件不接受修订、不删除批注；脱敏工作副本保留可处理的审阅结构，但作者等个人信息去标识化。

## XLSX

覆盖共享字符串、内联字符串、隐藏工作表、单元格、批注、批注作者、超链接和XML属性。除通用识别外，可由首个可识别表头为同列单元格提供有限字段提示；共享字符串多处复用时要查看全部预览坐标。命中以 `***` 显示；改动单元格自动换行，并按原列宽增大行高，避免遮盖符号被截断；不更改公式或全表列宽。数字、公式及缓存也检查；公式或工作表/命名范围等结构引用含敏感内容时阻断，不能把身份证直接换成文本后仍声称公式正确。无敏感内容的算术公式保留。纯数字身份标识转换为文本占位符；若工作簿同时存在公式，则保守阻断该转换，避免改变依赖计算。编辑后恢复不强行推断这类标识的原数字类型；需要精确原类型可取回原件。普通批注的 VML 为 XML，纳入扫描。

外部数据链接、数据连接、查询、透视缓存、图表缓存均阻断。不自动重算公式；用户在本机 Office/LibreOffice 打开后验算。

## PPTX

覆盖幻灯片、隐藏页、母版、备注、形状文本、替代文本及相关属性。备注与隐藏页不因不可见而跳过。

## 图片与扫描件

PNG/JPEG 重新编码，去除 EXIF；Office 内嵌 PNG/JPEG 同样经过本地 Tesseract。OCR 命中对应像素矩形实心黑块，垂直边界外扩4像素，水平按字符宽度额外外扩以覆盖OCR边缘误差；在本地页面显示原图、脱敏预览，并允许手动补充矩形。OCR 不识别人脸、手写签名、二维码语义；用户必须视觉检查并手动遮挡。没有 OCR 文本也不能省略图片确认。

GIF/TIFF/WebP/SVG/EMF/WMF、多帧图片不是本版原生支持对象；Office 遇到这些不支持媒体会阻断，不当作无隐私。

## PDF

逐页以180 DPI渲染，OCR定位后遮盖，重建只有图像的 PDF；不复制原始 PDF 的文字、附件、批注、元数据或历史对象。可见批注在渲染后属于页面像素，仍需检查。输出不再可搜索、不可原位编辑；最多60页，保留页面比例但不承诺原物理尺寸完全一致。恢复时仅按字节取回加密原件。

## 明确阻断与确定性清理

- 阻断：宏/旧式Office、损坏/加密未解锁文件、包类型不符、重复/路径穿越ZIP成员、DTD实体、未知二进制、OLE、ActiveX、altChunk、图表、动态数据源、数字签名包、复杂人员部件、非空自定义XML，以及敏感公式或结构引用。
- 可安全清理：空的标准书目 Sources 自定义XML及其属性部件；打印机设置二进制及引用（保留XML页面尺寸与页边距）；预览缩略图；XML注释与处理指令；Office属性值。
- 不删除非空书目库以冒充完成；这类输入需用户先制作静态工作副本。
- 单文件上限100 MiB，ZIP解压总量300 MiB，最多10,000成员，图片最多35,000,000像素；超限明确失败。

## 编辑后恢复

文本类格式精确替换当前任务的完整占位符，并核对每个文件的占位符数量。DOCX/XLSX/PPTX 的 `***` 标记按加密保险库中记录的文本单元和字符偏移恢复；缺少、移动、复制标记，或文本单元结构发生变化，均进入冲突清单且不写恢复稿。星号数量正确但语义位置被调换仍不能证明法律语义正确，恢复后必须本地复核。新文档若原本含 `***` 且造成标记歧义，恢复会失败关闭；可改为取回字节一致的原件。

批注与修订中的可见星号标记仅在原单元/偏移保持时恢复；文本类格式的完整 token 可精确恢复。外部增加的新文字保留，但不自动认定为安全。Office 内嵌图片只有其脱敏字节未改动时才取回原图片，否则阻断合并。整个图片被外部删除时不会重新强行插入；原图仍可通过取回原件获得。原文档属性不恢复到编辑后稿，以免把已清理元数据重新扩散。
