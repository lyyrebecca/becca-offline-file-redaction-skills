# 场景、材料组织与交付

## 产品逻辑

**一次安装固定引擎 → 每次选场景 → 本地识别与归属建议 → 人工确认 → 脱敏及整理 → 根据目的导出 → 独立加密恢复。**

不是让云端 AI 每次重写一套工具。日常识别不调用云端模型；Agent 只负责引导与读取无原文状态，不接触真实原文、词典、口令或映射。

## 身份 × 目的 × 接收对象 × 文件性质

| 身份 | 常见材料提示 | 本地复核重点 |
|---|---|---|
| 律师 | 诉讼文书、合同、证据、裁判材料 | 委托人保密、主体关系、策略与证据线索 |
| 法官 / 法院工作人员 | 裁判、程序、证据、课件 | 非公开材料、当事人及未成年人、公开规则不能由软件替代 |
| 企业法务 | 合同、交易、员工客户、调查资料 | 客户员工信息、内部项目、商业秘密 |
| 学生 / 研究者 | 教学课件、案例、研究资料 | 引用与个人信息区分、教学材料再分发边界 |
| 寻求法律意见的人 | 聊天截图、合同、流水、通知 | 对方及家属身份、支付账户、二维码、签名 |

身份是提示，不是访问权限。具体路由由文件格式与目的决定，不对某种职业降低保护。材料性质采用本地关键词给出可修改建议，不是经过训练的法律文书分类模型。

| 目的 | 默认处理 | 额外交付 |
|---|---|---|
| AI 分析 | 保留金额、日期及法院豁免，隐藏直接身份与案件标识 | 原格式副本＋Markdown＋材料/来源索引＋日期出现位置索引 |
| 外部审阅 | 同等基础识别，明确接收对象 | 原格式副本；需要时精确占位符恢复 |
| 课堂展示 | 图文均检查；手工框选签名、人脸、二维码 | PPTX，可选像素 PDF |
| 分发学生 | 在图文检查前，清除讲者备注、批注、隐藏页与失去引用的包部件 | 清理后的 PPTX，可选像素 PDF；编辑后恢复不重新加入被删除的私密页 |
| 公开分享 | 默认进一步识别日期、金额，取消法院的特殊豁免 | 原格式副本；仍需核对再识别风险和公开依据 |

接收对象选“公开公众”也会启用 public 基础规则；选择“学生”也清理 PPT 私有教学内容。日期与金额可以明确调整，调整不构成合法披露依据。AI / external 的基础识别算法相同，不能夸大成不同精度等级。

## 自动整理的实际能力

- 扫描所有材料后，本地按唯一明确案号或合同编号提出分组；多个标识、没有可靠标识的文件留为 PENDING。研究通用材料可建议 COMMON。
- 不凭相同姓名、文件名猜测并案。文件中的多个案号可能是引用先例，故不自动拆分多案文件。
- 用户逐份确认 CASE001、CASE002…与材料类别；PENDING 未解决时不能通过复核。
- 同一确认案件内，同类别同字面值复用占位符；跨案件不自动合并。COMMON 也构成一个共享作用域，若不同资料有同名不同人，需指定不同的“同名区分编号”或拆任务。
- 同名区分编号按命中项保存。同一编号且同字面值可合并；不同别称仍保留不同的精确恢复占位符，不能据此宣称已完成共指关系推理。
- 完全重复文件只标记，不删除、不去重。分类建议不自动排序事实时间或评价证据证明力。

## Markdown：方便读取，不虚构法律事实

只转换已复核脱敏内容，保留中性材料编号、区域编号、Office 包部件 / 单元格 / 图片或 PDF 页定位。Word 不编造页码。修订与可能隐藏的片段明确标记，不把删除文字拼成确定事实。复杂表格、图像仍需对照原格式副本；第一版不保证复杂阅读顺序或完整表格语义恢复。

OCR 文本在像素遮挡前完成占位符替换；手工矩形覆盖到的 OCR 行整体不导出，宁可少一些辅助文字，也不把手工遮住的内容重新带回 Markdown。图片视觉信息留在同目录脱敏文件，不生成未遮挡图片副本。

二次检查包含全文确定性规则与已知原文残留，以及每个来源文本块的本地 NER。生成的固定位置标记不按人名识别，避免中文模型把 `xml` 等机器锚点误识别人名。索引也检查；派生输出的校验失败会保留待复核状态，后续 verify 不能把它洗成通过。

## 目前不做

人脸/二维码自动识别、语义并案、多案文件自动切分、自动事实摘要、自动法律结论、企业审批与权限系统、云端软件托管、每任务动态生成代码、默认发送文件给 AI。自定义文字背景仅作为本机备注，不是自动执行的复杂政策指令。
