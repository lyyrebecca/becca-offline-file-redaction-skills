# 常见问题

### 我不用AI，或不是付费用户，也能用吗？
本地工作台可以独立运行，不要求脱敏API Key，不调用外部LLM。不需要先购买AI订阅；首次安装仍需准备本地依赖。GitHub/Codex等平台自身的账户政策不由本项目决定。

### 为什么名字很长，调用还是legal-privacy-cloak？
正式展示名是“终极·贝卡的文件脱敏离线部署软件 skills”；“信息隐身衣 / 贝卡文件脱敏”是工具简称。SKILL规范要求机器名采用小写和连字符，因此保留已有调用，避免旧任务和安装路径失效。

### 离线部署，是下载ZIP就什么都不用安装吗？
不是。发行包含程序与Skill，不含Python、OCR、中文模型或LibreOffice。需要先联网准备依赖，之后日常处理可以离线。严格空气隔离电脑的全量离线依赖镜像不在本次交付内。

### 文件怎么找？
结果页点“一键打开交付文件夹”，会在Finder打开share；点“复制文件夹路径”可手动前往。默认在`~/Documents/信息隐身衣任务/任务-随机号/share/`。不要发送整个任务目录。

### 为什么有PENDING，不是说自动分类吗？
软件只根据可靠标识提出归属建议，不会凭同名强行并案。缺少标识或含多个案号需要你确认；一个文件里混多个案件不会自动拆分。

### 姓名漏了，或不该打的被识别了怎么办？
在本机补充词典或正文漏检；误识别可取消遮挡并说明保留理由。高风险项不能因为白名单而自动免除复核。真实材料不要求上传给维护者排查。

### 人脸、签名、二维码会自动打码吗？
目前不保证自动识别；必须逐图看，必要时在原图拖动框选。OCR不能代替视觉复核。

### 同名不同人、同一个人的别称怎么处理？
同名的不同人逐命中填写不同区分编号，或拆任务。别称可以用案件词典明确身份关系，但保留不同精确恢复写法；不要把词面一致误当身份事实。

### PDF为什么不能搜索了？
默认渲染为像素、遮挡后重建，主动舍弃原文字层、附件与旧PDF对象。它更接近安全工作副本，不是保持全部可编辑能力的PDF编辑器。

### PPT我只删隐藏页就够了吗？
不够。学生模式同时清理备注、批注及失去引用的包部件；原图仍需复核。不是每种Office扩展部件都支持，遇到未知嵌入/动态内容会阻断。

### Excel为什么会阻断？
可能涉及敏感公式、缓存或计算依赖。直接替换可能改变计算或泄漏标识，因此宁可要求先制作安全静态副本，不静默破坏表格。

### 为什么不是所有文件都能一次通过？
真实OCR与中文识别会漏检或误识别，复杂部件也可能无法安全检查。待复核结果不是完成；不能改报告文字假装通过。

### 忘记保险库口令怎么办？
没有恢复后门。你需要自行另存原件、备份加密任务并保管口令；不要把口令发到聊天或Issue里。

### 外部编辑后能恢复吗？
支持现代Office/TXT/MD中完好且计数一致的任务占位符，保留其他编辑；改写、删除、复制占位符或改变待恢复图片会产生冲突。PDF/图片只取回原件，不合并外部修改。

### 这是法律意义上的匿名化吗？
可逆恢复属于去标识化/假名化。即使不可逆遮挡，也不自动等于法律匿名化。独特案情和关系组合仍可能识别当事人。

### Windows、Linux、手机能直接用吗？
本次正式验收为Mac电脑。其他平台没有完成桌面端到端验收；不提供已验证的.exe，也没有手机端交付。不要把可阅读Python代码误认为全平台已完成验证。

### 能给维护者发真实案件让你看看吗？
公开Issue只接收不含原文的版本/状态说明和合成样例。不要上传真实案件、身份证件、口令、保险库、映射、客户截图或恢复件。
