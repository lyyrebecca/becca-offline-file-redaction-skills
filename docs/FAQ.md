# 常见问题 · 2.4.2

### 不用 AI 或没有 API Key 能用吗？
能。依赖准备完成后可独立打开本地工作台，不调用外部 LLM。安装依赖与模型通常需要联网。

### 为什么不能下载后直接运行？
ZIP 包含 Skill 和源码，不捆绑 Python、中文模型、OCR 或 Poppler。先按[安装教程](INSTALL.md)准备环境；启动器不静默安装。

### 导入后还要逐份填案件号吗？
新版工作台每批默认同一案件，不再要求逐文件填案件编号/分类。多案分别新建任务，逐文件复核仍不可省略。

### 漏检、误检怎么办？
拖选漏检文字并选择类别，明确确认将精确同字面项传播至本批；相关材料需重新复核。右键单条候选可经二次确认取消遮盖。不同身份不能只凭同名推定相同。

### 数字和编码为什么没有自动打码？
新增低置信度数字/编码候选默认不打码，避免将所有编号都当成敏感信息。由用户逐项判断；已有高风险规则仍按各自规则处理。

### 学习库是训练 AI 吗？
不是。只记住明确新增的精确词条，使用口令加密保存在本机，未来任务同口令才载入。不做语义泛化，不推断跨案件身份。

### 图片、人脸、签名怎么处理？
逐张看图，必要时拖框。自动位置编号可跳转候选，手工框可移除重画。OCR 不是人脸、二维码或签名的自动检测保证。

### 三项人工确认都勾了，为什么还不能导出？
它们仅处理软性复核。2.4.2 会逐材料显示结构性阻断的代码和中文说明；点击返回相应材料，在本机制作可完整检查的静态副本后重新导入。未知代码同样阻断，没有忽略并继续导出的选项。

### 支持所有邮件或任意编码吗？
不支持。EML 只支持单段纯文本，HTML、多段和附件阻断，输出不可直接发送。普通文本格式要求 UTF-8（可带 BOM）；GBK/ANSI 不猜测解码，需先在本机另存 UTF-8。详见[格式边界](../references/formats.md)。

### 结果在哪？
结果页点“一键打开交付文件夹”或“复制文件夹路径”。默认任务位于系统文档目录的 `信息隐身衣任务`；只分享所需 `share/` 文件，不分享整个任务。

### 外部编辑后能恢复吗？
只能恢复符合条件的完好占位符。Office 显示 `***`，依赖原文本单元和原偏移等一致性检查，不能把任意星号当占位符；冲突时不伪装成功。PDF/图片只取回原件。口令遗失没有后门。

### Windows 和 Mac 都实测过了吗？
提供两套原生启动适配与双系统 CI。最新版证据见[验收范围](VERIFICATION.md)及对应提交 Actions；自动化、历史截图与实体桌面人工验收分开列，不互相冒充。没有手机版本。

### `CHECKED` 就能直接公开了吗？
不是。它仅表示本次机械检查和本地复核通过，不是零漏检、披露授权或法律匿名化认证。

### 谁制作的？可以把真实材料发来排查吗？
